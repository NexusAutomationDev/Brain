## Critical Gaps

### GAP-1: WebhookTransport.start() never injects runner (TRANS-02, SDK-02)

**File:** `packages/transport/src/webhook/handler.ts:81`

**Problem:** `WebhookTransport.start()` calls `createWebhookApp()` with no arguments. The handler's runner parameter is never populated at startup. All incoming webhook events fall through to the fallback path returning `{ status: "accepted" }` — BrainRunner.run() is never called.

**Fix required:**
```ts
// packages/transport/src/webhook/handler.ts
async start(port = 3000, runner?: IBrainRunnerLike): Promise<void> {
  const app = createWebhookApp(runner);
  // ...
}
```
Or: inject runner at construction time (`new WebhookTransport(runner)`).

**Impact:** The entire message-processing E2E flow is dead. Phase 4 (Validation Brain) cannot be built until this is fixed.

### GAP-2: createCoreApp not in barrel export (SDK-02)

**File:** `packages/core/src/index.ts`

**Problem:** `createCoreApp(runner)` is defined in `packages/core/src/server.ts` but not re-exported from the package's public API. Brain containers that need to mount the `/reload-prompts` endpoint must use internal import paths.

**Fix required:** Add to `packages/core/src/index.ts`:
```ts
export { createCoreApp } from './server.js';
```
