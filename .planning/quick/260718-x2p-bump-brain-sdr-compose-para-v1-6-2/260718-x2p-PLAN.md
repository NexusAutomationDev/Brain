# Task 260718-x2p: Bump brain-sdr compose de v1.6.1 → v1.6.2

## Contexto

O fix do consumer RabbitMQ (`queueOptions: { passive: true }`, commit a1e6338) foi
commitado e a tag de compose bumpada para `v1.6.1` (task 260718-o64). Porém em
produção o erro `PRECONDITION_FAILED - inequivalent arg 'durable'` persiste — sinal
de que a imagem `brain-sdr:1.6.1` no host/registry está **stale** (buildada antes do
fix ou não recriada). Prova: um declare passivo nunca gera "inequivalent arg durable";
o container está mandando declare ativo `durable:false` = código antigo.

Reusar a tag `1.6.1` é arriscado (host puxa imagem em cache). Usar uma tag **inédita**
`v1.6.2` força o CI/CD (`.github/workflows/publish-brain-sdr.yml`, dispara em push de
tag `v*.*.*`) a buildar imagem limpa e o host a baixar sem ambiguidade.

Bump **patch**: sem feature nem breaking change — apenas entregar em produção um fix
já commitado.
