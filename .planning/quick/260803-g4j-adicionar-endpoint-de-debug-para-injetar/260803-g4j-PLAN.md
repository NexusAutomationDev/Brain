<objective>
Adicionar um endpoint de debug/admin (`POST /debug/inject-message`) que injeta uma
`AIMessage` sintética direto no checkpoint LangGraph de um thread, via `updateState()` —
sem invocar o grafo nem gerar uma resposta real de LLM.

Purpose: não existe tabela SQL de "mensagens" — o histórico de conversa vive dentro do
checkpoint do LangGraph (canal `messages` do `BrainState`, persistido via `PostgresSaver`).
Simular uma mensagem que a IA "enviou" é útil para testar FUP, continuidade de conversa e
outros fluxos que dependem do histórico, sem depender de uma chamada real ao LLM.

Output: método público `BrainRunner.injectMessage(threadId, content)` + rota HTTP
`/debug/inject-message` protegida pelo mesmo padrão de auth de `/reload-prompts`.
</objective>
