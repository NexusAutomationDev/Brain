  <action>
Create `scripts/setup-test-db.sh` as a bash script that:

1. Reads PGHOST, PGPORT, PGUSER, PGPASSWORD from env (default to localhost, 5432, postgres, postgres).
2. Creates the `brain_test` database if it does not exist:
   ```
   createdb -h "$PGHOST" -p "$PGPORT" -U "$PGUSER" brain_test 2>/dev/null || true
   ```
3. Enables pgvector extension:
   ```
   psql -h "$PGHOST" -p "$PGPORT" -U "$PGUSER" -d brain_test -c "CREATE EXTENSION IF NOT EXISTS vector;"
   ```
4. Runs the Phase 1 migration using Drizzle Kit against the test database. Since drizzle-kit reads DATABASE_URL from .env, override via env:
   ```
   DATABASE_URL="postgres://$PGUSER:$PGPASSWORD@$PGHOST:$PGPORT/brain_test" \
   EMBEDDING_DIMENSIONS=10 \
   bunx drizzle-kit migrate --config packages/database/drizzle.config.ts
   ```
   (EMBEDDING_DIMENSIONS=10 matches FakeEmbeddings dimensions for test compatibility — see RESEARCH.md pitfall 6 and key finding 4.)
5. Print success message: `brain_test database ready.`
6. Make the script executable: `chmod +x scripts/setup-test-db.sh`

Also export `TEST_DATABASE_URL` from `.env.test` (create if not exists) as:
```
TEST_DATABASE_URL=postgres://postgres:postgres@localhost:5432/brain_test
EMBEDDING_DIMENSIONS=10
```

After creating the script, run it:
```bash
chmod +x scripts/setup-test-db.sh && bash scripts/setup-test-db.sh
```
