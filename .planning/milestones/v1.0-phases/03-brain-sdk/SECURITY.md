## Accepted Risks Log

| Threat ID | Rationale | Conditions |
|-----------|-----------|------------|
| T-3-02-01 | Prompt injection via DB requires direct DB access — out-of-scope for v1. UNIQUE constraint limits attack surface to one prompt per (brainType, key). `/reload-prompts` with auth is the only runtime reload path. | Revisit if multi-tenant or untrusted DB admins are in scope. |
| T-3-02-03 | Migration files generated by drizzle-kit and committed to git. Manual edits are prevented by convention, not enforcement. | Revisit in v2 with CI check to detect manual migration edits. |
| T-3-02-04 | `drizzle-kit generate` is a local, deterministic operation on TypeScript schema only. No DB connection needed or used. | No conditions — inherently low risk. |
| T-3-03-06 | `refreshPrompts()` reloads from DB and recompiles graph but does not call `process.exit(1)` on missing key (unlike `init()`). Container continues with prior prompts if refresh fails silently. | Revisit in v2: add explicit validation and alerting on refresh. |
