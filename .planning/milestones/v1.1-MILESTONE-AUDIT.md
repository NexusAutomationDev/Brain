## Critical Gaps

### GAP-1: Migration 0005 not in Drizzle journal (BLOCKER — SDR-01, SDR-04)

**Root cause:** `apps/brain-sdr/` has `packages/database/src/migrations/0005_brain_sdr_prompts.sql` with SDR prompt seeds, but `_journal.json` only has entries `0000`–`0004`. Drizzle's `migrate()` reads exclusively from the journal — 0005 is silently skipped.

**Impact chain:**
1. `BrainRunner.init()` → `runMigrations()` → Drizzle applies 0000–0004 only
2. `loadPrompts(sql, "sdr", ["system", "qualification"])` → returns empty map
3. `BrainRunner.init()` detects missing prompt keys → `process.exit(1)`
4. **brain-sdr container cannot start**

**Fix:** Run `drizzle-kit generate` for migration 0005 to register it in `_journal.json` + create `0005_snapshot.json`, OR manually add the journal entry and snapshot file.

**Affected requirements:** SDR-01 (unsatisfied), SDR-04 (unsatisfied)

---

### GAP-3: createTransport() not called by any Brain app (BLOCKER — TRP-06)

**Root cause:** `packages/transport/src/factory.ts` exports `createTransport(runner)` with `TRANSPORT=webhook|rabbitmq` ENV selection. However, `apps/brain-sdr/src/index.ts` and `apps/brain-echo/src/index.ts` both hardcode the Hono/webhook path directly — neither calls `createTransport()`.

**Impact:** Setting `TRANSPORT=rabbitmq` has zero effect on any deployed Brain. The RabbitMQ consumer is never started. The factory is a verified, tested, but orphaned export.

**Fix:** Update brain app entrypoints to call `createTransport(runner)` and start the returned transport, instead of always instantiating the Hono server directly.

**Affected requirements:** TRP-06 (partial)

## Minor Gaps

### GAP-2: ENV key mismatch in brain-sdr dev environment

`apps/brain-sdr/.env` sets `OPENAI_API_KEY=...` but `packages/ai/src/llm/factory.ts` reads `process.env.API_KEY`. In dev, if Bun loads only the app-level .env, the API key resolves to `undefined` → silent auth failure.

**Severity:** Info (dev-only; Docker runtime must supply correct ENV)  
**Fix:** Rename key in `apps/brain-sdr/.env` from `OPENAI_API_KEY` to `API_KEY`.

### INFRA-02: brain-sdr app missing lint script

`apps/brain-sdr/package.json` has no `"lint"` script. The 7 core packages all pass `turbo run lint`, but the SDR app is silently excluded from the lint pipeline.

**Note:** ROADMAP Phase 5 SC-3 specifies "todos os pacotes do monorepo (shared, database, observability, ai, memory, transport, core)" — the 7 core packages. INFRA-02 is satisfied per ROADMAP scope. This is a quality gap, not a requirement blocker.

**Fix:** Add `"lint": "eslint src/ --ext .ts"` to `apps/brain-sdr/package.json`.
