## Previous Audit Gaps — Status Update

### GAP-1: WebhookTransport.start() never injects runner — STATUS: RESOLVED (architectural workaround)

**Previous finding:** `WebhookTransport.start()` at `handler.ts:81` calls `createWebhookApp()` with no runner argument — BrainRunner.run() was never reached.

**Resolution:** `apps/brain-echo/src/server.ts` calls `createWebhookApp(runner)` directly (bypassing `WebhookTransport` entirely). SC-2 human smoke test confirmed the E2E flow works: `POST /api/v1/webhook → BrainRunner → LangGraph → "A capital do Brasil é Brasília."`.

**Remaining tech debt:** `WebhookTransport.start()` still creates the app without runner injection. The class is now unused in production, but any future consumer using `createTransport()` → `transport.start()` would silently serve a broken webhook. This should be addressed in v2 by either fixing the constructor signature or deprecating the class.

### GAP-2: createCoreApp not in barrel export — STATUS: FIXED ✅

**Resolution:** `packages/core/src/index.ts` line 19 now exports `createCoreApp` from `./server.js`. Confirmed by `apps/brain-echo/src/server.ts` importing and mounting it successfully.
