## v1.1 Requirements

### Transport

- [x] **TRP-01**: Webhook valida campos obrigatórios (Name, Message, Numero, IDLead) e rejeita com erro se algum faltar — Phase 5 (05-01)
- [x] **TRP-02**: WebhookTransport.start() injeta runner corretamente (correção GAP-1) — Phase 5 (05-01)
- [x] **TRP-03**: Transport RabbitMQ via rabbitmq-client consome fila com campos padronizados (Name, Message, Numero, IDLead) — Phase 7 (07-02)
- [x] **TRP-04**: Nome da fila RabbitMQ configurável via variável de ambiente — Phase 7 (07-02)
- [x] **TRP-05**: RabbitMQ opera com manual ack/nack, Dead Letter Exchange, prefetch=1 e reconexão automática — Phase 7 (07-02)
- [x] **TRP-06**: Seleção de transport via ENV `TRANSPORT=webhook|rabbitmq` — Phase 7 (07-02) + fix pós-audit `3e40494`

### Leads

- [x] **LEAD-01**: Tabela `leads` (id, unique_id app-generated, nome, numero, ia_ativada, fullpp) criada como substituta de `users` — Phase 6 (06-01)
- [x] **LEAD-02**: Lead cadastrado automaticamente na primeira mensagem — upsert por `numero`, `unique_id` gerado pela aplicação e nunca sobrescrito — Phase 7 (07-01)
- [x] **LEAD-03**: Mensagens de lead com `ia_ativada=false` são ignoradas silenciosamente antes de qualquer processamento pelo Brain — Phase 7 (07-01)
- [x] **LEAD-04**: Brain executa auto-migrate na inicialização — verifica e cria tabelas necessárias antes de aceitar mensagens — Phase 6 (06-02)

### Histórico de Conversas

- [x] **HIST-01**: `thread_id = lead.unique_id` — conversa vinculada ao lead via PostgresSaver, histórico recuperado automaticamente — Phase 8 (08-01)
- [x] **HIST-02**: Histórico completo persistido entre sessões — lead retornando dias depois tem contexto anterior recuperado — Phase 8 (08-01)
- [x] **HIST-03**: trimMessages ativo — limite de mensagens mantidas no contexto configurável via ENV — Phase 8 (08-02)

### Brain SDR

- [x] **SDR-01**: Brain SDR recebe mensagem, recupera contexto do lead e conduz conversa de atendimento inicial seguindo prompt do banco — Phase 9 (09-02, 09-03) + fix GAP-1 `e5475a3` | *human runtime test pending*
- [x] **SDR-02**: Brain SDR nunca processa lead com `ia_ativada=false` (via LeadService compartilhado) — Phase 9 (09-03) | *architecture verified; human runtime test pending*
- [x] **SDR-03**: Todas as interações do Brain SDR são registradas no banco — Phase 9 (09-03) | *architecture verified; human runtime test pending*
- [x] **SDR-04**: Prompts do Brain SDR armazenados no banco, zero hardcode, atualizáveis sem deploy — Phase 9 (09-01, 09-02) + fix GAP-1 `e5475a3`
- [x] **SDR-05**: Sub-agente de qualificação — acionado pelo Brain SDR com dois inputs: descrição e session_id; PostgresSaver.getTuple() busca histórico completo; retorna {qualificado, motivo, proximo_passo} — Phase 9 (09-02) | *LLM trust dependency for session_id; accepted*

### Infraestrutura

- [x] **INFRA-01**: TenantPoolManager ativado em produção no Brain SDR — seleção de banco via `DATABASE_NAME` ENV — Phase 9 (09-03)
- [x] **INFRA-02**: Lint configurado em todos os pacotes do monorepo — Phase 5 (05-02) | *7 pacotes satisfeitos; apps/brain-sdr excluded (non-blocking)*
