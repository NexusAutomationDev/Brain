## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DDL SQL → PostgreSQL | Arquivo SQL estático aplicado em banco de produção via runMigrations() |
| tables.ts → aplicação | Definições de schema Drizzle usadas por todos os pacotes downstream |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-01 | Tampering | 0007_v1_4_foundation.sql | mitigate | Migration é arquivo estático commitado no git — sem interpolação de variáveis de usuário. Revisão obrigatória via git diff antes de aplicar. Não usar `drizzle-kit generate` (Pitfall 1) que poderia gerar DDL não revisado. |
| T-19-02 | Denial of Service | ALTER TABLE leads ADD COLUMN | accept | ADD COLUMN com DEFAULT em PG 16 é operação O(1) via pg catalog — não bloqueia tabela. Risco de lock em tabela muito grande é baixo neste estágio do projeto. |
| T-19-03 | Information Disclosure | tables.ts EMBEDDING_DIM validation | accept | O throw em EMBEDDING_DIM inválido expõe o valor recebido; aceitável pois ocorre apenas em startup de processo interno, não em resposta HTTP. |
| T-19-04 | Tampering | _journal.json | mitigate | Journal commitado no git; alteração manual fora do workflow de migration quebraria `runMigrations()`. Entry idx=7 adicionada uma única vez por este plano. |
</threat_model>
