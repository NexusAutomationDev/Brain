# Milestone v1.1: Brain SDR + Infraestrutura Produção

**Status:** ✅ SHIPPED 2026-06-14
**Phases:** 5-9
**Total Plans:** 12

## Overview

Primeiro Brain real (SDR) implementado sobre a infraestrutura consolidada do v1.0. O milestone entregou: padronização do schema de eventos de transport, criação da tabela `leads` com auto-migrate, LeadService com upsert atômico e gate ia_ativada, RabbitMQTransport com ack manual e DLQ, histórico de conversas persistente via PostgresSaver vinculado ao lead, e o Brain SDR completo com grafo ReAct, sub-agente de qualificação stateless e imagem Docker multi-stage.

## Milestone Summary

**Key Decisions:**

- `rabbitmq-client@5.0.8` (não amqplib-bun) — zero deps, auto-reconnect built-in, Bun-compatible confirmado
- thread_id = lead.uniqueId (não Numero, não IDLead direto do payload) — derivado server-side após DB lookup
- DLQ via Publisher explícito (não DLX broker) — sem dependência de configuração específica de broker
- Slice de context window no nó do grafo (não no invoke()) — evita duplicação via messagesStateReducer
- Sub-agente de qualificação stateless (compile sem checkpointer) — lê histórico mas não persiste estado próprio
- Migration 0005 via _journal.json (fix pós-audit) — Drizzle exige entrada no journal para executar SQL
- createTransport() wired no index.ts do brain-sdr (fix pós-audit) — ENV TRANSPORT=rabbitmq agora ativa o consumer

**Issues Resolved:**

- GAP-1 (audit): migration 0005 não registrada no journal → corrigida com drizzle-kit generate
- GAP-3 (audit): createTransport() orphaned → wired no apps/brain-sdr/src/index.ts
- WebhookTransport runner injection (tech debt de v1.0) — corrigido na Phase 5 (constructor injection)
- TenantPoolManager não ativado em produção (tech debt de v1.0) — ativado no index.ts do brain-sdr

**Issues Deferred:**

- GAP-2: OPENAI_API_KEY → API_KEY no .env do brain-sdr (dev-only, não afeta Docker)
- INFRA-02: lint script ausente no apps/brain-sdr (fora do escopo original — 7 pacotes satisfeitos)
- MEM-03: semantic write path (dead code) — deferido para v2
- OBS-02: transport status no /health — deferido para v2
- users table obsoleta — deprecar em v2

**Technical Debt Incurred:**

- brain-echo/brain.test.ts — placeholder test expect(true).toBe(true) e LangGraph internal API access
