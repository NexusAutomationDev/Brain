  <action>
Executar os seguintes comandos em sequência para subir o container e verificar que responde:

**1. Confirmar que a imagem brain-echo-test existe (criada no plano 04-02):**
```bash
docker images brain-echo-test
```

Se não existir, rebuildar:
```bash
docker build -f apps/brain-echo/Dockerfile . -t brain-echo-test
```

**2. Subir o container com as env vars necessárias:**
```bash
docker run -d \
  --name brain-echo-test \
  --env-file .env \
  -p 3000:3000 \
  brain-echo-test
```

**3. Aguardar o container subir (migrations + init):**
```bash
sleep 5 && docker logs brain-echo-test --tail 20
```

**4. Verificar health check:**
```bash
curl -s http://localhost:3000/health | jq .
```
Esperado: `{ "status": "ok", "checks": { "db": "connected" } }`

**5. Enviar mensagem de teste (SC-2 smoke):**
```bash
curl -s -X POST http://localhost:3000/api/v1/webhook \
  -H "Content-Type: application/json" \
  -H "X-Request-Id: smoke-test-$(date +%s)" \
  -d '{"conversationId":"smoke-conv-1","stepIndex":0,"userId":"smoke-user","content":"Olá! Qual é a capital do Brasil?"}' | jq .
```
Esperado: `{ "status": "ok", "reply": "..." }` com reply não vazio.

**6. Rodar suite de integração com container ativo:**
```bash
ECHO_URL=http://localhost:3000 \
ECHO_CONTAINER_NAME=brain-echo-test \
bun test apps/brain-echo/src/__tests__/integration
```

**7. Capturar logs para o SUMMARY:**
```bash
docker logs brain-echo-test 2>&1 | tail -30
```
