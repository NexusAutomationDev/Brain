    In the "Request upload URL from DockGate" step (lines 59-62 in both files):

    **D-03 — Quote $RESPONSE:**
    Change line 62 from:
    ```yaml
    echo "URL=$(echo $RESPONSE | jq -r .url)" >> $GITHUB_OUTPUT
    ```
    to:
    ```yaml
    URL=$(echo "$RESPONSE" | jq -r .url)
    ```

    **D-04 — Validate URL before use:**
    After extracting URL, add validation block:
    ```yaml
    if [[ -z "$URL" || "$URL" == "null" ]]; then
      echo "ERROR: DockGate upload URL request returned invalid response"
      echo "Raw DockGate response: $RESPONSE"
      exit 1
    fi
    echo "URL=$URL" >> $GITHUB_OUTPUT
    ```

    **Why:** Unquoted $RESPONSE causes shell word-splitting if response contains spaces, breaking jq parsing with confusing errors. `jq -r .url` returns the literal 4-character string "null" (not empty) when field is missing — bash `[[ -z "$URL" ]]` test passes, allowing broken URL to propagate to curl with "Could not resolve host: null" instead of failing at the API step. Validation catches both empty and "null" string, prints raw response for debugging, and hard-fails the job immediately (Pitfall 1, 3 from 31-RESEARCH.md).

    Apply the EXACT same fix to both files — they're structurally identical (copied during Phase 30).
  </action>
