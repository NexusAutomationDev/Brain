<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Application → PostgreSQL | Connection strings contain credentials; must be env-only |
| Schema definition → database | DDL operations are privileged; schema must be validated before migration |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | DATABASE_URL in logs | mitigate | Never log DATABASE_URL; postgres.js onnotice: () => {} suppresses NOTICE logs containing credentials |
| T-02-02 | Information Disclosure | EMBEDDING_DIMENSIONS mismatch causing corruption | mitigate | Read from env and document in .env.example with WARNING comment; validate dimension range (128-4096) in future enhancement |
| T-02-03 | Tampering | SQL injection via schema | accept | Schema uses Drizzle ORM type-safe builders; no raw SQL strings in table definitions |

</threat_model>
