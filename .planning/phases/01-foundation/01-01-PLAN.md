<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File system → monorepo config | Root package.json, pnpm-workspace.yaml, and turbo.json are trusted inputs (developer-controlled) |
| tsconfig paths → package resolution | Path aliases resolve to local packages only; no external resolution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Denial of Service | Turborepo cache | accept | Turborepo cache corruption could slow builds but is local-only (dev machines, CI); no production impact |
| T-01-02 | Tampering | pnpm-lock.yaml | mitigate | Pin packageManager in package.json to "pnpm@11.5.3"; lock file ensures deterministic installs |
| T-01-03 | Information Disclosure | Build artifacts in dist/ | accept | Local development only; production images built in isolated CI; no secrets in source |
| T-01-04 | Elevation of Privilege | npm scripts in package.json | mitigate | All scripts run as current user; no sudo or privileged operations; code review required for script changes |

</threat_model>
