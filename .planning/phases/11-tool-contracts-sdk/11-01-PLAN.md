    async setFullpp(uniqueId: string, value: boolean): Promise<void> {

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ENV → ToolsRegistry | `process.env.BRAIN_TOOLS` é lido no runtime — operador do container controla o valor |
| LangGraph Config → Tool | `config?.configurable?.thread_id` passa pelo LangGraph — o BrainRunner é quem seta o thread_id, não o LLM |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | `process.env.BRAIN_TOOLS` CSV parsing | accept | Valor controlado pelo operador do container (não exposto ao usuário final); parse `.trim()` previne espaços acidentais |
| T-11-02 | Spoofing | `thread_id` via RunnableConfig | mitigate | D-05/D-06: `thread_id` é definido pelo BrainRunner (`lead.uniqueId`), nunca vem do payload do LLM; schema `z.object({})` impede LLM de injetar lead_id |
| T-11-03 | Elevation of Privilege | Tool BRAIN_TOOLS bypass | mitigate | Guard em `enableTool()` (não em `getTools()`) — tool não entra no registry se não está na whitelist; D-07: silêncio previne enumeration de tools disponíveis |
</threat_model>
