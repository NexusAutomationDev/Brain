<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Compose healthcheck → /healthz | Container orchestration loops poll /healthz multiple times per minute |
| External operator → /readyz | Misconfigured monitoring can hammer /readyz; cache prevents storms (PITFALL — probe storms) |
| OS signal (SIGTERM) → uvicorn → lifespan | Compose `docker stop` sends SIGTERM; window before SIGKILL is `BRAIN_SHUTDOWN__GRACE_SECONDS` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Denial of Service | unbounded /readyz probe storms hammer Postgres + RabbitMQ + Qdrant | high | mitigate | `_CACHE_TTL_S = 5.0` in `health.py`; tests assert cache window respected; D-06 |
| T-05-02 | Denial of Service | a hung Postgres connection blocks /readyz forever, masking liveness | high | mitigate | `_PROBE_TIMEOUT_S = 2.0` + `asyncio.wait_for`; on timeout returns "timeout" string and 503 — process stays responsive |
| T-05-03 | Information Disclosure | /readyz body leaks internal hostnames or connection strings on failure | medium | mitigate | Probe handlers return ONLY the string `"ok"`/`"timeout"`/`"error"` — no exception messages, no DSN fragments propagate to body |
| T-05-04 | Denial of Service | SIGTERM ignored, request stuck → SIGKILL drops in-flight HTTP responses | high | mitigate | uvicorn `--timeout-graceful-shutdown` (= `BRAIN_SHUTDOWN__GRACE_SECONDS`, default 30s) + FastAPI `lifespan` closes deps in reverse; integration test asserts clean rc=0 |
| T-05-05 | Tampering | Multiple uvicorn workers break in-process persona cache + lock registry (Assumption A4) | medium | mitigate | `workers=1` hardcoded in `brain.api.main`; horizontal scale via more containers per ARCHITECTURE.md §Concurrency |
| T-05-06 | Tampering | Lifespan crashes during startup → port not bound but container "running" | medium | mitigate | FastAPI lifespan exceptions during startup prevent uvicorn from binding the port (cited in RESEARCH.md Pattern 5); compose healthcheck (added in plan 01-07/01-08) fails fast |
| T-05-07 | Information Disclosure | Lifespan logs `settings.auth.token` or `settings.postgres.dsn` in startup_complete event | high | mitigate | Lifespan logs only `service` + `grace_seconds` keys — no settings echo; AUTH-03 test in plan 01-03 enforces no provider keys outside settings.py; verify the `startup_complete` log line in tests does not contain secrets |
| T-05-08 | Denial of Service | Langfuse subsystem unreachable but Brain blocks on it (PITFALL 8.1) | high | mitigate | Lifespan does NOT touch Langfuse (D-11); Phase 4 wires fire-and-forget; Phase 1 /readyz does NOT probe Langfuse |
