```dockerfile
# syntax=docker/dockerfile:1.7
# Multi-stage build for Brain. Three targets:
#   - builder : compiles the venv with uv + cache mounts
#   - dev     : adds dev deps; uvicorn --reload
#   - prod    : non-root, slim, HEALTHCHECK, uvicorn --workers 1
#
# Base image policy (CLAUDE.md §9): python:3.12-slim-bookworm.
#   NOT alpine (musl breaks psycopg[binary] + ML wheels)
#   NOT 3.13 (LangGraph ecosystem wheels still lag)
#   NOT :latest (CLAUDE.md §10 — pin every tag)

ARG PYTHON_IMAGE=python:3.12-slim-bookworm
ARG UV_IMAGE=ghcr.io/astral-sh/uv:0.11.16

# ─────────── Stage 1: builder ───────────
FROM ${PYTHON_IMAGE} AS builder

# Copy uv from the official image (A6 — pin matches CLI version in pyproject)
COPY --from=ghcr.io/astral-sh/uv:0.11.16 /uv /uvx /bin/

ENV UV_COMPILE_BYTECODE=1 \
    UV_LINK_MODE=copy \
    UV_PYTHON_DOWNLOADS=never \
    PYTHONDONTWRITEBYTECODE=1

WORKDIR /app

# Install deps without copying source — cacheable layer keyed on lockfile + pyproject
RUN --mount=type=cache,target=/root/.cache/uv \
    --mount=type=bind,source=uv.lock,target=uv.lock \
    --mount=type=bind,source=pyproject.toml,target=pyproject.toml \
    uv sync --frozen --no-install-project --no-dev

# Now copy source + install the project itself
COPY pyproject.toml uv.lock alembic.ini /app/
COPY src /app/src
COPY alembic /app/alembic

RUN --mount=type=cache,target=/root/.cache/uv \
    uv sync --frozen --no-dev

# ─────────── Stage 2: dev ───────────
FROM builder AS dev

# Add dev deps on top of the frozen venv
RUN --mount=type=cache,target=/root/.cache/uv \
    uv sync --frozen

# Bring in tests (dev image runs pytest from inside the container)
COPY tests /app/tests
COPY scripts /app/scripts

ENV PATH="/app/.venv/bin:$PATH" \
    PYTHONUNBUFFERED=1

EXPOSE 8000
CMD ["uvicorn", "brain.api.app:app", "--host", "0.0.0.0", "--port", "8000", "--reload"]

# ─────────── Stage 3: prod ───────────
FROM ${PYTHON_IMAGE} AS prod

# Non-root user (DEPLOY-03)
RUN groupadd --system --gid 1001 brain \
 && useradd  --system --uid 1001 --gid brain --home-dir /app --shell /sbin/nologin brain

# Copy only what prod needs — no uv binary, no dev deps, no tests, no scripts/lint
COPY --from=builder --chown=brain:brain /app/.venv          /app/.venv
COPY --from=builder --chown=brain:brain /app/src            /app/src
COPY --from=builder --chown=brain:brain /app/alembic        /app/alembic
COPY --from=builder --chown=brain:brain /app/alembic.ini    /app/alembic.ini
COPY --from=builder --chown=brain:brain /app/pyproject.toml /app/pyproject.toml

WORKDIR /app

ENV PATH="/app/.venv/bin:$PATH" \
    PYTHONUNBUFFERED=1 \
    PYTHONDONTWRITEBYTECODE=1 \
    PYTHONPATH="/app/src"

USER brain
EXPOSE 8000

# HEALTHCHECK uses Python stdlib (slim image has no curl/wget). Liveness only — not /readyz.
# /readyz would 503 if MQ/Qdrant flap; using /healthz means container restart triggers
# only when the process itself is unresponsive.
HEALTHCHECK --interval=10s --timeout=3s --start-period=20s --retries=3 \
    CMD python -c "import urllib.request,sys; \
        sys.exit(0 if urllib.request.urlopen('http://127.0.0.1:8000/healthz',timeout=2).status==200 else 1)"

# Default CMD launches uvicorn. brain-migrate compose service overrides this:
#   command: ["python", "-m", "brain.db.migrate"]
# A4: --workers 1 (in-process lock registry + persona cache; horizontal scale = more containers)
# D-13: --timeout-graceful-shutdown reads BRAIN_SHUTDOWN__GRACE_SECONDS from env at container start
# (`sh -c` because uvicorn's CLI flag doesn't natively expand env vars in argv)
CMD ["sh", "-c", "uvicorn brain.api.app:app --host 0.0.0.0 --port 8000 --workers 1 --timeout-graceful-shutdown ${BRAIN_SHUTDOWN__GRACE_SECONDS:-30}"]
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dev host filesystem → docker build context | Files NOT in `.dockerignore` are visible to the build (including `.env` if present locally) |
| prod container → host kernel | Non-root user limits escalation paths |
| prod container → external network | Healthcheck reaches loopback only; container internet egress is governed by compose (plan 01-08) |
| supply chain (PyPI via uv, GHCR via uv image) → builder | Builder dependencies inherit upstream trust |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Information Disclosure | `.env` inadvertently copied into image (PITFALL 4) | high | mitigate | `.dockerignore` excludes `.env` and `.env.*`; `!.env.example` keeps example committed but the env-file substitution at runtime is via compose `env_file:`, not image bake |
| T-07-02 | Elevation of Privilege | Prod container runs as root → arbitrary file writes + escalation potential | high | mitigate | Prod stage creates `brain` user (uid 1001) and sets `USER brain` before EXPOSE/CMD; acceptance test verifies via `docker run id` |
| T-07-03 | Tampering | `:latest` Python or uv image silently changes between builds (CLAUDE.md §10 + A6) | high | mitigate | `ARG PYTHON_IMAGE=python:3.12-slim-bookworm`; uv image pinned to `0.11.16`; grep acceptance forbids `:latest` |
| T-07-04 | Tampering | musl-based alpine image breaks `psycopg[binary]` or ML wheels at runtime | medium | mitigate | `-slim-bookworm` (glibc) per CLAUDE.md §9; grep acceptance forbids `alpine` |
| T-07-05 | Denial of Service | HEALTHCHECK using `curl` fails because the slim image has no curl → container endlessly unhealthy | high | mitigate | HEALTHCHECK uses Python stdlib `urllib.request` (always available in any python image) |
| T-07-06 | Tampering | Source from `tests/` or `.planning/` lands in prod image → larger attack surface + leaks dev notes | medium | mitigate | `.dockerignore` excludes both; prod stage only `COPY --from=builder` the venv + `src/` + `alembic/` + `alembic.ini` + `pyproject.toml` |
| T-07-07 | Denial of Service | `--timeout-graceful-shutdown` not passed → uvicorn waits indefinitely on a stuck request during SIGTERM | high | mitigate | Prod CMD uses `sh -c` to expand `${BRAIN_SHUTDOWN__GRACE_SECONDS:-30}` into the flag value at container start; D-13 |
| T-07-08 | Tampering | `gunicorn` accidentally adopted (CLAUDE.md §10 anti-recommendation) | medium | mitigate | grep acceptance forbids `gunicorn` in Dockerfile |
| T-07-09 | Information Disclosure | Build context too large — secrets in unrelated dev files leak via build logs | medium | mitigate | `.dockerignore` keeps context small (< 50 MiB typical); README excludes via `!README.md` pattern |
| T-07-10 | Elevation of Privilege | dev image used in prod by mistake (has dev deps, uvicorn --reload) | medium | accept | dev/prod are explicit `--target` choices in compose; plan 01-08 uses `target: prod` exclusively |
</threat_model>
